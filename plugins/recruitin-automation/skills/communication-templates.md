# Skill: Communication Templates

## Purpose
Generate context-appropriate communication for all recruitment scenarios.

## Activation
Auto-activated when `{{OPERATION_TYPE}}` is: `daily_routine`, `deal_rescue`, `content_creation`, `crisis_management`

## Template Categories

### 1. Client Communication
#### Initial Outreach
```
Subject: [Specific value proposition] voor [Company]

Beste [Naam],

[One-sentence hook referencing their specific situation/need].

Bij RecruitIn helpen we [type bedrijven] met [specific outcome].
[One concrete proof point: recent placement, market insight, or data point].

Zou het interessant zijn om [specific, low-commitment next step]?

Met vriendelijke groet,
[Naam]
RecruitIn
```

#### Follow-up (no response)
```
Subject: Re: [original subject]

Beste [Naam],

Ik begrijp dat [empathetic reason for no response — busy season, etc].

Kort: [one new value-add: market insight, relevant candidate mention, industry trend].

Als de timing nu niet past, wanneer zou een goed moment zijn?

Groet,
[Naam]
```

#### Deal Progress Update
```
Subject: Update [Role/Project] — [Stage summary]

Beste [Naam],

Hier een update over de voortgang:

**Status:** [current stage]
**Kandidaten:** [count] in proces, [count] in [stage]
**Timeline:** [expected next milestone]

**Volgende stappen:**
1. [Action + who + when]
2. [Action + who + when]

Vragen of aanpassingen? Laat het weten.

Groet,
[Naam]
```

### 2. Candidate Communication
#### Opportunity Introduction
```
Subject: [Role title] bij [Company type/description]

Beste [Naam],

[One line — why you're reaching out to THEM specifically].

De rol: [2-3 bullet points — key responsibilities]
Waarom interessant: [2-3 bullet points — growth, culture, compensation]

Staat u open voor een kort gesprek deze week?

Met vriendelijke groet,
[Naam]
RecruitIn
```

#### Interview Preparation
```
Subject: Voorbereiding gesprek [Company] — [Date]

Beste [Naam],

Goed nieuws — uw gesprek met [Company] staat gepland op [date/time].

**Gesprekspartner(s):** [Names + roles]
**Format:** [Type, duration]
**Locatie/Link:** [Details]

**Voorbereiding tips:**
1. [Company-specific insight to mention]
2. [Question to ask that shows interest]
3. [Skill/experience to emphasize]

**Praktisch:**
- [Dress code / tech check]
- [Arrival time / login time]

Succes! Bel me gerust als u nog vragen heeft.

Groet,
[Naam]
```

#### Rejection (respectful)
```
Subject: Update over [Role] bij [Company]

Beste [Naam],

Bedankt voor uw tijd en interesse in de [Role] positie.

Na zorgvuldige overweging is de keuze op een andere kandidaat gevallen.
[If possible: one specific, honest reason without being hurtful].

[If appropriate: "Ik houd u graag in gedachten voor toekomstige mogelijkheden
die beter aansluiten bij uw profiel."]

Ik wens u veel succes.

Met vriendelijke groet,
[Naam]
```

### 3. Internal Communication
#### Deal Escalation
```
**[ESCALATION] Deal: [Name] — €[Value] — Risk: [Level]**

**Situation:** [2 sentences]
**Attempted:** [What's been tried]
**Blocked by:** [Specific blocker]
**Need:** [Specific help needed]
**Deadline:** [When this becomes irreversible]
```

## Usage Rules
- Always personalize — never send template as-is
- Dutch by default, English when context requires
- Adapt formality to relationship stage (first contact = formal, ongoing = warmer)
- Include merge fields for Pipedrive: `{contact.name}`, `{deal.title}`, etc.
